The Anthropogenic Impact Accounting Ontology Suite provides a comprehensive semantic framework for representing anthropogenic impact accounting data in a machine-readable format. The suite currently consists of four specialised ontologies, each published at a permanent W3ID address that resolves to its documentation and machine-readable files.

| Ontology | W3ID | Source |
|---|---|---|
| Anthropogenic Impact Accounting Ontology | [w3id.org/aiao](https://w3id.org/aiao) | [GitHub](https://github.com/Accountable-Impact-Commons/aiao) |
| Claim Ontology | [w3id.org/claimont](https://w3id.org/claimont) | [GitHub](https://github.com/Accountable-Impact-Commons/claimont) |
| Impact Ontology | [w3id.org/impactont](https://w3id.org/impactont) | [GitHub](https://github.com/Accountable-Impact-Commons/impactont) |
| Information Communication Ontology | [w3id.org/infocomm](https://w3id.org/infocomm) | [GitHub](https://github.com/Accountable-Impact-Commons/infocomm) |

**Impact Ontology** provides the foundational vocabulary for modelling impact: an activity, the environment it affects, and the change that connects them.

**Anthropogenic Impact Accounting Ontology** extends that foundation to human activity and the accounting of its effects, from greenhouse gas emissions to ecosystem outcomes.

**Claim Ontology** models defeasible claims, the agents that make them, and the substantiation that supports or refutes them.

**Information Communication Ontology** models the communication of information itself, so that reports, disclosures and messages can be described as events with senders, receivers and content.

The ontology files can be retrieved over HTTP by automated or manual means, which makes them usable directly from code as well as from a browser.
